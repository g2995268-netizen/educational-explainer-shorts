# templates/bridge

Base scaffold for educational explainer shorts (flat vector style).

## How to use
1. Copy this entire folder to `src/videos/<your-short-name>/`
2. Register a new composition in `src/Root.tsx`
3. Edit `story.ts` — define shots and timings
4. Replace the placeholder ShotRenderer in `Explainer.tsx` with real scenes
5. Use values from `look.ts` for colors, outlines, typography
6. Follow `references/STYLE_BIBLE.md` for character design and composition

## Files
- Explainer.tsx — main composition
- story.ts — shot plan and timings
- look.ts — colors, outlines, palettes
