# STYLE_BIBLE
**Educational Explainer Shorts — Flat Vector Style**

## 1. Формат
- Aspect ratio: 9:16
- Длительность: 55–75 секунд
- Темп: быстрый, кадр меняется каждые 1.5–3.5 секунды
- Текст: белый/чёрный с обводкой, синхронизирован с голосом
- Камера: в основном статичная, редкие лёгкие push-in или reveal

## 2. Визуальный язык
- Flat vector / 2D cartoon с жирными тёмными контурами
- Высокая насыщенность, ограниченная палитра на сцену
- Мягкие тени, иногда свечение на ключевых объектах
- Минимальные текстуры

## 3. Персонажи
- Простые геометрические формы
- Крупные выразительные глаза
- Антропоморфные объекты (вирусы, органы, клетки)
- Одежда и аксессуары плоские и яркие

## 4. Ключевые приёмы
- Объект с лицом (вирус, клетка, орган)
- Инфографика (карты, диаграммы, стрелки, проценты)
- Слой / разрез (мозг, органы, синапсы)
- Морфинг объектов
- Циклическая рамка (начало = конец)
- Reveal камерой (интерфейс → отъезд к персонажу)
- Split-screen
- Частицы и объекты в воздухе
- Микро-анимация действий (нажатие кнопки, дуновение)

## 5. Цветовые палитры
- Тревога: красный + фиолетовый + чёрный
- Наука / космос: глубокий синий + фиолетовый + белый
- Повседневность: жёлтый, зелёный, голубой
- Интерфейс / AI: тёмно-синий + неоновые акценты

## 6. Композиция
- Центр кадра — главный объект
- Движение в основном внутри кадра
- Текст не перекрывает ключевые элементы

## 7. Повествование
- Обычно один голос за кадром
- Допускается диалог
- Структура: хук → объяснение → визуализация механизма → вывод
