# Motion

## Targets
- Camera: mostly static or very slow drift / push-in
- Internal motion preferred (particles, diagrams, character reactions)
- Hard cuts or simple morphs / fades
- No handheld shake
- Every hold longer than ~10 frames should have some creeping motion

## Timing
- Visual reaction lands 0–3 frames before the corresponding word
- Transitions: 6–15 frames typical
- Avoid frozen frames ≥12 frames

## Preferred moves (from references)
- Object morphing
- Split-screen reveals
- Camera pull-back from interface to character
- Particle / object flight
- Cyclical framing (start and end on same visual)
